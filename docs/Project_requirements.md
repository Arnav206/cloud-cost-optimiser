A. Problem statement
 
cloud users often struggle to compare infrastructure costs and identify opportunities to reduce expenditure because cloud pricing models, resource configurations, and usage patterns differ.

B. Project objectives

Compare cloud resource pricing across AWS, Azure, and GCP.
Estimate costs for user-defined workloads.
Recommend cost-effective resource configurations.
Identify underutilised resources using usage data.
Forecast future cloud expenditure using machine learning.

C. MVP features

User-defined workload requirements.
Cloud resource comparison.
Estimated monthly cost calculation.
Cheapest suitable configuration recommendation.
Basic cost comparison reports.
